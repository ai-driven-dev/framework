# Learnings

Which review feedback outlives its pull or merge request.

| Feedback | Becomes |
| --- | --- |
| a preference stated as a general one, such as "docs too long" | a learning |
| the same remark on several files | one learning, linking every thread |
| a decision another change would face again | a learning |
| what a project rule or memory already says | that rule named as not followed, no new learning |
| a one-off change | nothing |
