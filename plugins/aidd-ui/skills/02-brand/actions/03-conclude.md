# 03 - Conclude

Leave a brand that validates, and tell the user what follows.

## Input

`<engine>` and the file written.

## Process

1. Run `node <engine> validate` and fix each error line in `aidd_docs/ui/brand.md` as its `=> fix` says. Repeat until none is left there; the errors [engine](../references/engine.md) says a later step owes stay.
2. Reply to the user with:
   - the brand written;
   - what `validate` still prints;
   - that the code is untouched.

## Output

The reply to the user.
