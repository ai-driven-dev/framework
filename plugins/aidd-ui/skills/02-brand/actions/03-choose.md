# 03 - Choose

Keep the direction the user chooses.

## Input

The set, compared.

## Process

1. Give the user the comparison page.
   - Say how to return the feedback.
2. Wait for the feedback.
3. Read the feedback file beside the page.
   - Else write the pasted feedback there.
4. Read it per [variants](../references/variants.md).
   - If no direction stands out, ask what to change, then read [propose](02-propose.md).
5. Keep the chosen variant per [engine](../references/engine.md).
6. Read [conclude](04-conclude.md).

## Output

The brand kept, and the set gone.
