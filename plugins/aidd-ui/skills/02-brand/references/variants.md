# Variants

A direction is a variant of the brand.

## Set

- Name the set `brand`.
- Each direction folder holds a `brand.md` and a `preview.html`.
- In an evolution, start each direction from the current brand.
- The set's `variants.md` lists each direction.
  - Its name, round, parent, intent and axes.

## Rounds

- Round 1: three directions, two to five if the user asks. Far apart.
- Next round: the mix, plus two directions close to it.
  - Picked axes stay as picked. Only the others move.
  - Parent: the direction the mix starts from.
  - "Go further" in a comment: move the others further.
- Earlier rounds stay in the set.

## Axes

An axis is one choice on which the directions differ.

- Draw the axes from the subject and the exchange.
- Name each axis in the user's plain words.
- In each cell, name the reference it draws on, if any.
- Write a palette as hex values: background, text, accent.
- Name the type with its family: sans-serif, serif or monospace.

## Preview

- It shows the direction at work.
- Show its name, its words and one screen of the subject.
- It carries its own styles.
- The showcase dresses the project's wireframes in the palette and type.
