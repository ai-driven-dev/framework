# Variants

A direction is a variant of the brand.

## Set

- Name the set `brand`.
- Each direction folder holds a `brand.md` and a `preview.html`.
- In an evolution, start each direction from the current brand.
- The set's `variants.md` lists each direction: its name, its intent, its axes.

## Axes

An axis is one choice on which the directions differ.

- Draw the axes from the subject and the exchange.

## Preview

- It shows the direction at work.
- Show its name, its words and one screen of the subject.
- It carries its own styles.
