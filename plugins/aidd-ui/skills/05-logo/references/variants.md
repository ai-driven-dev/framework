# Variants

A direction is a variant of the logo.

## Set

- Name the set `logo`.
- Each direction folder holds the kit at its paths under `aidd_docs/ui/`, and a `preview.html` at its root.
- The set's `variants.md` lists each direction: its name, its intent, its axes.

## Axes

An axis is one choice on which the directions differ, such as the symbol's shape, the type style or the palette.

- Draw the axes from the brand facts and the exchange.

## Preview

- It shows each kit file at 16, 32 and 128px.
- It shows them on a light and on a dark background.
- It carries its own styles.
