# 02 - Propose

Propose at least two directions for the logo.

## Input

The output of [prepare](01-prepare.md).

## Process

1. Draw at least two directions from the brand facts and the exchange.
   - Follow [variants](../references/variants.md).
   - Change: start each direction from the current logo files.
2. Write each direction's kit per [kit](../references/kit.md), each record from the [logo](../assets/logo-template.md) template.
3. Compare the set per [engine](../references/engine.md).
   - Fix what it reports, and compare again until it accepts.
4. Read [choose](03-choose.md).

## Output

The set of directions, compared.
