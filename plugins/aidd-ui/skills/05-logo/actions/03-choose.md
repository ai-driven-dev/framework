# 03 - Choose

Keep the direction the user chooses, and record it in the history.

## Input

The set, compared, and the task folder.

## Process

1. Give the user the comparison page.
   - Ask them to paste the copied feedback here.
2. Wait for the feedback.
3. Weigh the feedback.
   - A discarded direction is out, whatever its rating.
   - Read a comment as a reason, not as an order.
   - Two ratings close together: ask what separates them.
   - Let the rating guide the choice the user makes.
   - If no direction stands out, ask what to change, then read [propose](02-propose.md).
4. Keep the chosen variant per [engine](../references/engine.md).
5. Record each kit file in the history per [engine](../references/engine.md).
   - Creation: record it as created.
   - Change: raise it with one line saying what changed.
6. Read [conclude](04-conclude.md).

## Output

The logo kept, recorded in the history, and the set gone.
