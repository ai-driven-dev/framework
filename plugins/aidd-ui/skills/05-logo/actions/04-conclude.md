## Input

## Process

1. Validate per [engine](../references/engine.md).
2. Fix each error line on a `logo-` file as its `=> fix` says.
3. Validate again per [engine](../references/engine.md), and repeat until only the errors it says another skill owes remain.
4. Reply with:
   - the logo files written, with their versions
   - what the validation still prints
   - that the code is untouched
   - that each logo file is `proposed` until the user publishes it per [engine](../references/engine.md), after looking at it

## Output
