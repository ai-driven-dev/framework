# 02 - Propose

Give the user the pages to review.

## Input

The records to review, and the captures to save.

## Process

1. Write the showcase per [engine](../references/engine.md), in the project memory's language.
2. Look at each page per [look](../references/look.md).
   - Never edit a record: tell the user what reads badly.
3. Give the home page first, then each record's page.
   - The review panel, on every page, gathers every verdict.
   - A coded screen shows its captures beside each render.
   - Name each missing capture.
4. Ask them to review each state, then paste the panel's copy here.
5. Wait for the paste.
6. Read [choose](03-choose.md).

## Output

The pages, given.
