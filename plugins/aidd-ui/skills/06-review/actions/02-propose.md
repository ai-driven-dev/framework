# 02 - Propose

Give the user the pages to review.

## Input

The records to review, the language, and the captures to save.

## Process

1. Write the showcase per [engine](../references/engine.md), in the user's language.
2. Give the user the page of each record.
   - A coded screen shows its captures beside each render.
   - Name each missing capture. The user saves it: the engine never runs the app.
3. Ask them to review each state.
   - Ask them to paste the copied block of each record here.
4. Wait for the pastes.
5. Read [choose](03-choose.md).

## Output

The pages, given.
