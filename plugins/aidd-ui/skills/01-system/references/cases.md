# Cases

| Case | When |
| --- | --- |
| from scratch | no `aidd_docs/ui/system.md`, no UI code; propose the brand and the tokens first, components when a screen asks for them, the user free to add more |
| from the code | no `aidd_docs/ui/system.md`, UI code exists |
| new elements | `system.md` exists, the request adds tokens or elements |
| change | `system.md` exists, the request changes, deprecates or removes a token or an element |
