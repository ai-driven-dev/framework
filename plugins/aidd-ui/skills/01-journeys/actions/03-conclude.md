# 03 - Conclude

Leave journeys and wireframes that validate, and tell the user what follows.

## Input

`<engine>` and the files written.

## Process

1. Run `node <engine> validate`.
2. Fix each error line in the folders this skill writes.
3. Follow its `=> fix`, until none is left.
4. Keep the `warning` lines.
5. Keep the errors [engine](../references/engine.md) says a later step owes.
6. Reply with:
   - the journeys and wireframes written or raised, with their versions
   - each component the R18 warnings name, for the design system to add
   - that each journey and wireframe written is `proposed` until its review.

## Output

The reply to the user.
