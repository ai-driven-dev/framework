# Variants

A variant is another way to dress one wireframe.

## Set

- Name the set after the screen's id.
- Each variant folder holds `screens/<id>.md` and `screens/<id>.html`.
- The render is the preview: no other file is needed.
- The set's `variants.md` lists each variant: its name, its intent, its axes.

## Axes

An axis is one choice in how the screen is built.

- Take it from the wireframe: zone order, density, emphasis, navigation.
- Keep the same zones and states in every variant, so they compare.
- Use tokens only, never a literal.
