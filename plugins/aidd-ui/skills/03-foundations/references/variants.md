# Variants

A variant is a whole alternative of the foundations.

It may hold the system record, tokens and themes.

## Set

- Name the set after what varies, such as `tokens`.
- A variant folder mirrors `aidd_docs/ui/`, with only the files it changes.
- The tokens and the stylesheet follow the kept variant, once.

## Axes

An axis is one decision that variants answer differently.

- Take it from a token group: spacing rhythm, text contrast, radius, motion.
- Take it from the system record: themes, platforms, breakpoints.
- Tie each to the brand direction, never to a trend.
