# Code errors

Errors about the code. The skill never fixes them: the code stays untouched.

| Rule | Meaning |
| --- | --- |
| C4 | a colour literal in the code, beyond the debt recorded |
| C6 | a physical property in the code, for a right-to-left locale |
| C10 | a value of a `code-tokens` file differing from the stylesheet's |
