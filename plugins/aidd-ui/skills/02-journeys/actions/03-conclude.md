# 03 - Conclude

Leave journeys and wireframes that validate, and tell the user what follows.

## Input

`<engine>` and the files written.

## Process

1. Run `node <engine> validate` and fix each error line under `aidd_docs/ui/journeys/` or `aidd_docs/ui/wireframes/` as its `=> fix` says. Repeat until none is left there; the `warning` lines and the errors [engine](../references/engine.md) says a later step owes stay.
2. Reply to the user with:
   - the journeys and wireframes written or raised, with their versions;
   - each component a wireframe expects that the design system lacks, from the R18 warnings: named, never created here;
   - that each journey and wireframe written is `proposed` until its review.

## Output

The reply to the user.
