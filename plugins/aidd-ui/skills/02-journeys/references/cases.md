# Cases

| Case | When |
| --- | --- |
| from scratch | no journey under `aidd_docs/ui/journeys/`, no UI code: the persona and the journeys come from the user |
| from the code | no journey under `aidd_docs/ui/journeys/`, UI code exists: journeys and wireframes are deduced from its real screens |
| change | a journey exists: the request adds a journey, or changes one or a wireframe |
