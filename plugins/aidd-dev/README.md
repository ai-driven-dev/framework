# aidd-dev

Code: plan, build, validate, review, debug.

| | |
| --- | --- |
| Status | stable |
| Install | `/plugin install aidd-dev@aidd-framework` |
| Start with | `/aidd-dev:01-plan` |

## Skills

| Skill | Use it to |
| --- | --- |
| [`/aidd-dev:01-plan`](skills/01-plan/SKILL.md) | Turn a request or a ticket into a phased plan |
| [`/aidd-dev:02-implement`](skills/02-implement/SKILL.md) | Write a plan's code, phase by phase |
| [`/aidd-dev:03-assert`](skills/03-assert/SKILL.md) | Check the work against the project's assertions |
| [`/aidd-dev:04-audit`](skills/04-audit/SKILL.md) | Assess a codebase, read-only |
| [`/aidd-dev:05-review`](skills/05-review/SKILL.md) | Review a diff before you ship it |
| [`/aidd-dev:06-test`](skills/06-test/SKILL.md) | Write tests, or walk a journey in the browser |
| [`/aidd-dev:07-refactor`](skills/07-refactor/SKILL.md) | Clean up, speed up, harden or restructure code |
| [`/aidd-dev:08-debug`](skills/08-debug/SKILL.md) | Reproduce a bug, then fix it |
| [`/aidd-dev:09-for-sure`](skills/09-for-sure/SKILL.md) | Retry until a command passes |
| [`/aidd-dev:10-batch`](skills/10-batch/SKILL.md) | Run independent tasks in parallel |

## Agents

| Agent | Use it to |
| --- | --- |
| `executor` | Turn a scoped task into working code, in its own context |
| `checker` | Judge finished work against the real need, in a fresh context |
