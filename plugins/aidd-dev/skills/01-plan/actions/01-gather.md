# Gather

## Input

A request, file, or ticket.

## Output

Source kind and reference, requested outcome, hard constraints.

## Process

1. **Resolve.** Read the file, fetch the ticket, or use the supplied text; ask for a source if none exists.
2. **Restate.** Summarize the outcome and constraints in bullets with bold labels.

## Rules

- **Fidelity.** Invent no source content, solution, or phases.
