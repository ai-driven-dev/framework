# 01 - Capture

Settle what the plan rests on.

## Input

The user's request.

## Process

1. With no source to plan from (file, ticket, or text), ask for one and stop.
2. Read it, noting what it asks and the constraints it states.
3. Read [explore](02-explore.md).

## Output

What was understood, kept for explore, with the source's reference (path, ticket id, or text).
