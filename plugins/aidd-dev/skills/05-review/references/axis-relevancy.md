# Axis: relevancy

Take the need and read the project's declared rules, never assuming one. Record each misfit under its lens, tied to a rule, a site or the need; a bare opinion is no finding.

- `fit`: drift from the real intent, end to end, not only the literal criteria.
- `conform`: a violation of a declared rule, naming it.
- `rot`: duplication, over-engineering or incoherence, a document the change now contradicts included, citing the site.
