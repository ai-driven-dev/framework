# Axis: relevancy

Read the need and the project's declared rules, then record each misfit under its lens, tied to a rule, a site or the need.

| Lens | Misfit |
| --- | --- |
| `fit` | drift from the need, end to end, or a change it does not ask for |
| `conform` | a declared rule violated, naming it |
| `rot` | duplication, over-engineering, incoherence, or a document the change contradicts |
