# 02 - Review

Read the diff through each axis and keep what holds.

## Input

The diff, the need and the axes.

## Process

1. Read the [rubric](../references/rubric.md).
2. Apply each chosen axis to the diff, in parallel when you can:
   - `code`: [axis](../references/axis-code.md);
   - `functional`: [axis](../references/axis-functional.md);
   - `relevancy`: [axis](../references/axis-relevancy.md).
3. Merge what several axes found into one finding, at its strictest severity.
4. Read [conclude](03-conclude.md).

## Output

The rated findings, the limits, and the criteria with their score.
