# 02 - Review

Review the diff.

## Input

The diff, the need and the axes.

## Process

1. Read the [rubric](../references/rubric.md).
2. Name the behaviour the diff changes, and for whom.
3. List what it assumes about its inputs, callers and environment, and what the plan or a comment claims; check each where the value is produced or used.
4. List what the diff should have changed and did not: a caller, a test, a document, a migration.
5. Apply each axis, in parallel when you can: [code](../references/axis-code.md), [functional](../references/axis-functional.md), [relevancy](../references/axis-relevancy.md).
6. Keep one finding per defect, whichever step found it.
7. Read [conclude](03-conclude.md).

## Output

The findings, the limits and the criteria.
