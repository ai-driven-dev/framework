# 02 - Review

Read the diff through each axis.

## Input

The diff and the axes.

## Process

1. Read the [rubric](../references/rubric.md).
2. Apply each axis, in parallel when you can: [code](../references/axis-code.md), [functional](../references/axis-functional.md), [relevancy](../references/axis-relevancy.md).
3. Keep one finding per defect, whichever axes found it.
4. Read [conclude](03-conclude.md).

## Output

The findings, the limits, and the criteria with their score.
