# 03 - Conclude

Judge the round and keep it.

## Input

The diff, the axes, the findings, the assumptions, the limits, the criteria, and the plan or task folder if any.

## Process

1. Set the verdict per the [rubric](../references/rubric.md).
2. Fill a round from the [review template](../assets/review-template.md).
3. Append the round to the `review.md` of the task folder named, else of the plan's; with neither, ask whether to keep it in a file:
   - yes: in the work's feature folder, `aidd_docs/tasks/<yyyy_mm>/<yyyy_mm_dd>_<feature-slug>/`;
   - no: the reply holds it.
4. Read the round back against `review-template.md`, fix each gap, and repeat until it matches.

## Output

The verdict and its round, with the report path when written.
