# 01 - Prepare

Settle what is reviewed.

## Input

The work, and its plan, criteria, ticket, task folder or evidence if any.

## Process

1. Take the work: the one named, else the branch against its pull request target or default branch, uncommitted changes included, the report excluded. None: stop and say so.
2. Take the axes named, else all of them, `functional` only with a plan or criteria; named without them, ask.
3. Read [review](02-review.md).

## Output

The diff and the axes.
