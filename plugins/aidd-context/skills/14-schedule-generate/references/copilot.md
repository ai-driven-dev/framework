# GitHub Copilot

- Interactive CLI. `/every INTERVAL PROMPT` repeats and `/after DELAY PROMPT` runs once. The creating session must stay open. Open either command without arguments to inspect entries. [CLI schedules](https://docs.github.com/en/copilot/how-tos/copilot-cli/automate-copilot-cli/schedule-prompts)
- Cloud. In an eligible private or internal repository, open Agents → Automations. Choose the schedule, prompt and tools. [Cloud automations](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/cloud-agent/create-automations)
- VS Code. Use `/automate` in the Agents window. Local schedules require an awake machine and an available agent. Custom cron requires a local Agent Host. [VS Code automations](https://code.visualstudio.com/docs/agents/run/automations)
