# Kilo Code

- Surface. Kilo Cloud Agent offers scheduled triggers in beta. The execution environment needs a connected repository and an agent environment profile. Check that the selected skills are available there. [Cloud Agent](https://kilo.ai/docs/code-with-ai/platforms/cloud-agent)
- Setup. Open Webhooks / Triggers, choose Scheduled, select the repo and profile, and put the rendered prompt in the trigger's prompt template. Use the frequency picker or cron with the requested timezone. UTC is the default. The minimum interval is ten minutes. [Scheduled triggers](https://kilo.ai/docs/code-with-ai/platforms/cloud-agent#scheduled-triggers)
- Verify. Reopen the saved trigger to compare its prompt, cron, timezone and active state. Request History shows the session and status once a run has occurred. [Cloud Agent in Markdown](https://raw.githubusercontent.com/Kilo-Org/kilocode/main/packages/kilo-docs/pages/code-with-ai/platforms/cloud-agent.md)
