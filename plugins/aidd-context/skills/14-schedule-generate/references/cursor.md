# Cursor

1. Target a Cursor cloud agent automation. Use the Automations page or the built-in `/automate` skill in a local agent session. Select a Scheduled trigger and enter the recurring preset or cron expression. Confirm the effective time zone in the host before using wall-clock hours.
2. Put the complete prompt in the automation instructions. A scheduled trigger defaults to no repository. Select the repository when the task reads its files or skills, and enable the tools its steps need.
3. After saving, reopen the automation and check its trigger, prompt, repositories, tools and enabled state. Scheduled runs may begin later than the selected time.
