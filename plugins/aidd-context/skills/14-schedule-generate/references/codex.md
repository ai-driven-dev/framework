# Codex

1. Use the scheduled-task interface in the desktop app. From a Codex chat, describe the cadence, time zone, project, and whether the run starts a fresh chat or returns to this one. For an advanced standalone schedule, use the custom schedule control's RFC 5545 recurrence rule.
2. Supply the full prompt and name the skills the task should use. For project work, select the local directory or an isolated Git worktree. The project must be on disk with the computer awake and the app running.
3. After saving, open Scheduled and compare the saved prompt, effective schedule, project and active state. When only the standalone CLI is available, hand back the prompt and desktop settings.
