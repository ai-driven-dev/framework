# Review protocol

Review a generated skill, file by file, then once as a whole.

1. **Read** each file, its cited references, and only the sibling files needed to verify a concrete claim.
2. **Flag** each breach of `skill-authoring.md`, with a reason and a `file:line`.
3. **Check** once, across the skill, that the diagram matches `actions/` (R8).
4. **Check** each file against the questions of its kind in `fill-norm.md`.
5. **Return** the flags. Do not edit any file.
