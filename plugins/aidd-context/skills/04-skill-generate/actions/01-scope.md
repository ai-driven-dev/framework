# 01 - Scope

Frame a new skill before any file is touched.

## Input

A free-form request to create a skill whose folder does not exist.

## Process

1. Detect the installed tools per [tool-detect.md](../references/tool-detect.md).
2. Fill [scope-frame.md](../assets/scope-frame.md), proposing each field's value or asking one question.
3. Check the name per [naming.md](../references/naming.md), and state any overlap with an installed skill, or that none was found.
4. Confirm the frame with the user, then continue to [plan](02-plan.md).

## Output

The confirmed frame, written nowhere, per `scope-frame.md`.

## Rules

- Write no file.
- Ask one question at a time, only for a field you cannot propose.
