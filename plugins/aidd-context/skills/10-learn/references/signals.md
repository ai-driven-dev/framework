# Signals

What a source holds that is worth keeping, and which source to read.

## Signals, in order

| Order | Signal |
| --- | --- |
| 1 | The user corrected the AI |
| 2 | An error, or an attempt repeated |
| 3 | A choice made with its reason |
| 4 | Information that had to be searched or asked for |

## Keep or drop

| Case | Verdict |
| --- | --- |
| Holds for anyone working on the project | Keep |
| A personal taste | Drop |
| Specific to the task in progress | Drop |
| Has no passage of the source to cite | Drop |
| A bug fix, unless it teaches a rule for other code | Drop |

## Source

| Case | Source |
| --- | --- |
| No hint | The current conversation |
| Hint names a file, a diff or a review | That one, read in the smallest slice that explains the lesson |
| A past conversation | The report of a conversation review, never the review itself |
