# 01 - Capture rule

## Input

A free-form rule request.

## Output

Approved candidates/resolution or confirmed sources, with operation and destinations.

## Process

1. **Frame.** Apply [Framing](../references/rule-authoring.md#framing).
2. **Compare.** Assess candidates through [Discovery](../references/tool-paths.md#discovery) and [Assessment](../references/rule-authoring.md#assessment).
3. **Decide.** Present the assessment and request the user's decision.

## Rules

- Never proceed with unresolved conflicts/uncertainty.
