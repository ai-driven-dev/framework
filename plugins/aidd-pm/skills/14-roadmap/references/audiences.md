# Audiences

| Element | Team view | Stakeholder view |
| --- | --- | --- |
| Outcome and theme | yes | yes, in the audience's words, with no new claim |
| Placement | month or horizon | the granularity the user picks for this audience |
| Commitment | all levels | `committed` and `planned`; `exploring` only when the user includes it |
| Trace | ticket ids and paths | none |
| Estimates and capacity | yes | none |
| Dependencies and risks | yes | only those the user chooses to share |
| Items the user excludes | yes | none |
| Progress flags | yes | only `done`, shown as `delivered`, on an update |
| Change log | yes | none |

The stakeholder view never promises more than the team view commits.

A client or sales audience gets the stakeholder view. Its caveat line is the user's own words.
