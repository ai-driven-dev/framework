# Handoffs

Offer the named capability with what was observed, then stop. Never invoke it silently, never write outside a roadmap.

| Observed | Capability | Return |
| --- | --- | --- |
| an item with no stated outcome | Epic | the item stays a `proposal` until the Epic exists |
| an opportunity with no framing | Product Brief | the item stays `exploring` until the brief exists |
| a priority the user wants settled by evidence | a decision capability | placement waits for the decision |
| a placed item that needs slicing | User Story | one-way; the roadmap keeps the item |
| no match | none | report what was observed |
