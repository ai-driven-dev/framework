# Counting

## Units

| Unit | Counts | Does not count |
| --- | --- | --- |
| Item | one ticket, message, email, note, review, or transcript passage read from a source | a reply that only quotes an earlier item |
| Comment | an item where a voice from the plan's population speaks to a topic, first-hand or relayed | a team member's own opinion |
| Verbatim | a comment holding that voice's exact words, first-hand | a paraphrase, a summary, or a relayed quote |
| Distinct voice | one customer or account, counted once per topic | the same account seen in several items |

## Rules

| Rule | Applies as |
| --- | --- |
| Meaning over keyword | an item joins a topic when it meets the definition; a keyword hit alone is excluded and logged |
| One item, one count per topic | an item may join several topics, once each |
| Duplicates | the same statement forwarded or copied counts once, at its earliest date |
| Date | the date the voice spoke, not the date the item was filed |
| Window | items dated outside the plan's window are excluded and logged |
| Buckets | week or month, as set in the plan, never changed after collection |
| Trend | claimed only when every bucket compared meets the plan's minimum count |
| Reproducibility | every figure equals a filter over the ledger; the dashboard names the plan version and read dates |
