# Interview

Ask in this order, one question per turn. Skip a row the context already answers.

| Topic | Ask | Why it matters |
| --- | --- | --- |
| Decision | What decision do you have to make, and by when? | a dashboard without a decision measures nothing |
| Options | Which options are on the table, including doing nothing? | evidence is weighed per option, not in general |
| Current belief | What do you believe today, and what is it based on? | exposes the intuition the data will test |
| Change of mind | What would you need to see to change your mind? | sets the bar before the data, so it cannot move after |
| Topics | Which themes or problems should we track? | each topic becomes one counted row |
| Population | Whose voice counts: customers, prospects, churned accounts, internal teams? | fixes who a comment must come from |
| Sources | Where do these signals live today? | bounds what can be collected |
| Window | Over which period, and why that one? | makes counts comparable and trends readable |
| Stakes | What does a wrong call cost? | sets the confidence the decision needs |

| Case | Handling |
| --- | --- |
| The PM names topics but no decision | ask for the decision first |
| The PM wants the dashboard now | explain that counts need agreed definitions, then continue with the next question |
| The answer is a solution, not a decision | ask which problem it solves and what the alternative is |
| The PM has no change-of-mind criterion | offer two concrete examples drawn from their options and ask them to pick or adapt |
