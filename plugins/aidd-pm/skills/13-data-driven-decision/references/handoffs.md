# Handoffs

Offer the named capability with what was observed, then stop. Never invoke it silently.

| Observed | Capability | Return |
| --- | --- | --- |
| no decision can change with the answer | none | report what was observed |
| data too thin and the decision cannot wait for more | Spike | one-way; the memo is its evidence |
| a population is silent or known only second-hand | user interviews | back to `collect` with the syntheses |
| decision taken to explore a new opportunity | Product Brief | one-way; the memo is its evidence |
| decision taken to build | Epic or User Story | one-way |
| a topic is a product malfunction | Defect | one-way |
