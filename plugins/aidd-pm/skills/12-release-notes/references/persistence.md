# Persistence

| Situation | Result |
| --- | --- |
| explicit target | use it |
| notes exist for this release and audience | update them and keep their identity |
| no target given | write `aidd_docs/releases/<release-slug>/<audience>.md`, the release name in kebab-case |
| the user declines a write | keep the notes in the session |

Markdown is the only support this skill writes.
