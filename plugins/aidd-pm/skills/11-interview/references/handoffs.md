# Handoffs

Offer the named capability with what was observed, then stop. Never invoke it silently, never write outside a guide or synthesis.

| Observed | Capability | Return |
| --- | --- | --- |
| evidence for a product opportunity | Product Brief | one-way; the synthesis is its interview evidence |
| themed insights across several interviews | a data-driven decision capability | one-way; the insight table is its input |
| a user describing an observed product mismatch | Defect | one-way |
| a need bounded enough for one deliverable behavior | User Story | one-way |
| no match | none | report what was observed |
