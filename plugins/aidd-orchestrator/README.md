# aidd-orchestrator

Runs other skills end to end.

| | |
| --- | --- |
| Status | stable |
| Install | `/plugin install aidd-orchestrator@aidd-framework` |
| Start with | `/aidd-orchestrator:01-sdlc` |

## Skills

| Skill | Use it to |
| --- | --- |
| [`/aidd-orchestrator:01-sdlc`](skills/01-sdlc/SKILL.md) | Deliver a request from framing to a draft pull request |
| [`/aidd-orchestrator:00-async-dev`](skills/00-async-dev/SKILL.md) | Turn issues into pull requests without you |
| [`/aidd-orchestrator:02-backlog`](skills/02-backlog/SKILL.md) | Triage, refine, order and check a product backlog |
