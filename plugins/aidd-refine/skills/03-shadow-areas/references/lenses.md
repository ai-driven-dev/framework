# Lenses

Where a source usually leaves a builder guessing.

| Element | Spot it as | Ask it |
| --- | --- | --- |
| Actor | a person, role or system | Who triggers, decides, is told? |
| Action | a verb | Who does it? What if it fails, times out, runs twice? |
| Data | a field, record or message | From where? Who may change it? What if missing or malformed? |
| Term | an adjective or domain word | Could two builders read it two ways? |
| Bound | a number, limit or duration | What at zero, at the limit, past it? |
| External | a service, API or prior step | Which one? What if it is down? |
| Requirement | a must, shall or will | How does a test pass or fail it? |
| Premise | a condition a sentence needs | What must already be true? |

- A question the source answers elsewhere is no gap.
