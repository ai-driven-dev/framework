# Plugin skills

## Grid

- `SKILL.md` is a router: it picks an action and holds no work.
- The description says when to use and when not to, in 240 characters at most.
- The router names every action; none hides in an unlisted sub-folder.
- An action has inputs, outputs, steps and one `## Test` form.
- No link leaves the skill and none names another plugin.
- Steps are numbered with one label form.
- A diagram stays only if it shows a real flow.

## Conventions

- R1 to R19 live in `plugins/aidd-context/skills/04-skill-generate/references/skill-authoring.md`; read it, do not copy it.
- Check the form with `check-skill.cjs`, beside that reference.
