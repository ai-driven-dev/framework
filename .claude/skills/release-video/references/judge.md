# Judge

What the check cannot read; each row is answered on a plan before it is accepted.

| Question | Rewrite or remove when |
| --- | --- |
| Would a user notice this change? | it is a correction with nothing to see, such as a lost figure now flagged: no scene, it stays in the release notes |
| Does a two-word phrase need a glossary? | yes: say what the user can do now, or drop the scene |
| Is the feature shown in the tool the user works in? | a Codex feature appears in a terminal: put it in a Codex window |
| Is a story told in the order lived? | do it, then see the report by tool, in one scene each |
| Is a safety feature shown as it unfolds? | it only states the result: show the warning in red, then the question put to the user |
| Does the picture say it with the sound off? | a scene needs the music or a read of the notes to be understood |
| Does the demo look believable? | an invented value is not marked as an example, or the command is not a real one |
| Do the intro tags name this release's big features? | they could open another release, or need a phrase to be understood: rewrite them |
