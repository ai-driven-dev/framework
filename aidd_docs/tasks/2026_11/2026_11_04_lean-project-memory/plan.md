## Rules

| Rule | Why it applies |
| ---- | -------------- |
| A skill is a router; actions hold the steps, references the tables | the method used for assert and review |
| No rule stated twice | the format rules live in the engine; the skill keeps one table |
| A plugin never holds its own tests | rule and hook tests go in `scripts/__tests__/` |
| A guard ships with the violation that proves it | every new CLI guard has a planted case, planted by the checker, never by the guard's author |
| After phase 7, an executor never edits a guard, raises a baseline or touches a shared primitive to turn a gate green | a red gate is fixed in the code it names; the checker diffs guard files and baselines at each phase |
| The checker is never the author; gates run in the foreground | an agent that ends its turn on a background job is never resumed |
| Bounded contexts, hexagonal layers, one fact one home | `cli/.claude/rules/00-architecture/` |
| No dates or ticket IDs in code or docs | templates, code and docs stay timeless |
| English only in code, tests, docs and plan files | the repository's language |

## Decisions

| Decision | Why |
| -------- | --- |
| The skill writes the AI's memory and one README, nothing for the team to fill | `GUIDELINES.md` and `CONTRIBUTING.md` are never loaded by the AI |
| Memory holds the macro view; detail lives in the owner plugin's folder (`aidd_docs/ui/`, aidd-pm's folder) | a second description drifts; `backlog.md` keeps five to eight lines of team decisions |
| Format is checked by the hook at each write and by the engine at check; the model judges only content | a lexical rule a model applies is applied unevenly |
| Check prints its findings in three blocks and writes a file only on request | a report file under `tasks/` is left behind as noise |
| Existing team files are never removed | the skill only stops creating them |
| The bank is read at its root, and a file is where it belongs | a misplaced capability file is flagged, never duplicated |
| Sections are free; the hook checks lines only | 16 of 41 real bank files would fail a section check |
| 24 templates become 14 files, 6 always written, 8 only when the scan finds something | each section answers a question an agent would otherwise get wrong |
| A renamed template keeps its former file names in `capabilities.md` | an old file is offered a merge |
| Refresh ends with sync, on the tools already wired | the memory block never lags |
| Two hook levels, inform and require, at two moments, after the write or at the turn end, chosen by when the artifact is final | a multi-write artifact is final only at the turn end; never a blocked write; full rules in `hook-contract.md` |
| Only a plugin with a turn-end check keeps state: one file per session listing the paths the turn wrote | without it, Stop would walk the project every turn and meet standing errors |
| A gap's level is set by measurement on four real banks | a level 2 rule must have no false positive |
| A missing always-written file: level 1 at each write, level 2 at the skill's check | during setup the other files are not written yet |
| `memory.cjs hook|check|sync` replaces three scripts; sync stages nothing in git | one entry per concern; a hook never runs git |
| The memory block lists the folders other plugins own | a plugin added later reaches every host, SessionStart text does not |
| Framework hooks speak Claude's protocol; the CLI converts every other host | one converter tested on real payloads instead of host code copied into each plugin |
| One hooks descriptor per tool; adding a tool is a descriptor and a payload fixture | what differs per tool is data |
| The levels bind the framework, not users | `08-hook-generate` asks the user's intent instead |
| A rerun of `translate` into a non-empty folder is a stated limit | no real flow does it; the engine's strip-then-add covers it anyway |
| aidd-pm's folder move and the aidd-dev plan hook are separate changes | each is its own concern and plugin |
| Measured on Haiku first, then Qwen 3.8 Flash; Sonnet left out | a skill that holds on the smaller model holds on the larger one |
