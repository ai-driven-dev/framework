## Test Scope

| Scenario   | Action | Observable outcome | Actor |
| ---------- | ------ | ------------------ | ----- |
| Setup      | consenting clone from the shared fixtures, on a working branch with no declaration | ready state | system |
| Happy path | `task.cjs remind` gets a Claude Code SessionStart payload | one `systemMessage`: `Telemetry: no task on <branch>. aidd telemetry task <name> [--ticket <ref>] when you want.`, no `additionalContext`, exit 0 | system |
| Edge case  | branch declared by the command | prints nothing | system |
| Edge case  | default branch or detached HEAD | prints nothing | system |
| Edge case  | clone not consenting, `AIDD_TELEMETRY=0`, or a payload of another tool | prints nothing, git not asked when no interval is open | system |
| Edge case  | Codex SessionStart payload on an undeclared working branch, through the Codex adapter | what refacto-cli's adapter prints for `person`, else nothing | system |
| Edge case  | consent key turned off by hand | the open interval is closed, as the deleted `session-start.cjs` did (test of line 717 moved here) | system |
| Edge case  | malformed or empty stdin, unknown event | prints nothing, exit 0 | system |
| Edge case  | a UserPromptSubmit on an undeclared branch | no hook entry for it in `hooks.json`, the prompt is never blocked | system |
| Teardown   | remove the temp clone and telemetry dir | baseline restored | system |
