## Test Scope

| Scenario     | Action                  | Observable outcome   | Actor                           |
| ------------ | ----------------------- | -------------------- | ------------------------------- |
| Setup        | template `# T {{x}}` > `## Round {{n}}` > `### A`, `### B` | fixture ready | system |
| Happy path   | doc with two rounds, each `### A` then `### B` | no finding | system |
| Edge case    | unknown `### C` under a round | finding names `C` as not in the template | system |
| Edge case    | `### B` before `### A` | finding names `A` or `B` out of order | system |
| Edge case    | `### B` missing, then listed in `optional` | missing finding, then none | system |
| Edge case    | second `# T demo` in the body | finding "one title only" | system |
| Edge case    | `### C` inside a fence and inside an HTML comment | no heading finding | system |
| Edge case    | round 2 holds a table whose header differs from the template | header finding on round 2 | system |
| Edge case    | existing ops tests and repo run | unchanged results, baseline.json unchanged | system |

## Tasks to do

### `1)` Heading tree in shape and parseTemplate

> Read every heading level, keep children per heading.

1. In ops.cjs `shape()`, build a tree of headings levels 1..6 from prose lines; keep title, line, body lines and table headers per heading.
2. In `parseTemplate()`, build the same tree; a heading whose name has a slot gets `repeat` and a name matcher.

### `2)` Check children at every level

> Same rules as today, applied per parent.

1. For each doc heading matched to a template heading, compare its children: unknown named, out of order unless repeat, missing unless in `optional`.
2. Flag a second level-1 heading: "one title only".
3. Check table headers on every instance of a matched heading, each round included, not only the first.
4. Update the op's doc comment: tree rule, unique title, `optional` takes bare names and a name shared by two parents is ambiguous.
