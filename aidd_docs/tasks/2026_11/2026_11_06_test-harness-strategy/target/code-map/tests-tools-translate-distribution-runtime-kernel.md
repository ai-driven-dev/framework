Scope: every file under `tests/contexts/tools/`, `tests/contexts/translate/`, `tests/contexts/distribution/`, `tests/runtime/` and `tests/kernel/`, mapped to the target test layout. Paths are relative to `cli/`. Tests mirror the target `src/` layout; a command test keeps its level suffix (`add-marketplace.unit.test.ts`).

Profile test merge: the 45 per-tool parallel files split by the document 04 estimate, 34 of 60 lines or fewer merge into the conformance suite and its kit, and the 11 longer ones stay as per-tool files limited to what is specific to that tool. Document 07 expects a `profile` file per tool; with that estimate only Kilo keeps one (138 lines), the others are covered by conformance. Merged files are dropped only after each case is read: a case written identically in 3 profiles moves up, a case differing by a datum becomes a bounded `it.each`, and the relevance rule decides the rest.
