# Phase 4: Native agents and workflows

Historical instruction: [related historical commit](https://github.com/ai-driven-dev/framework/commit/781125f8ac5e2138ca018b433543c686b2674263). Historical status: `done`. Current scope status: retained.

## Architecture projection

- Agents are Markdown files under `.kilo/agents/`; the filename supplies the agent name and only documented frontmatter is emitted.
- Workflows are Markdown files under `.kilo/commands/`; only supported, requested frontmatter is emitted.
- Keep the existing target-specific generation flows and preflight collision/invalid-field refusals.

Current implementation: `plugins/aidd-context/skills/06-agent-generate/` and `plugins/aidd-context/skills/07-command-generate/`.

## Test Scope

Artifact contracts, supported fields, path/collision behavior, and limited Kilo runtime inspection. Current CI checks the saved agent/command fixtures through Kilo debug/config output. A separate E2E invokes a workflow written inside the test; it does not invoke the checked-in workflow fixture or the agent fixture. Older local runtime transcripts remain historical only.
